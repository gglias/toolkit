Tool 01 · QR code

QR code generator

Static codes that never expire. Style them to your brand, check they scan, then export SVG for print or PNG for the web.

Runs on this page. Nothing is uploaded.
ContentLink

Need to change it after printing?

A static code can't change. So point it to a page on your own domain, like yoursite.com/qr/menu, and redirect that page wherever you need (in WordPress, the free Redirection plugin does it).

You can change the destination any time, see the scans in Analytics, and no QR service can switch your printed codes off.

Guests scan it and join, no typing. Best printed for a reception desk or a table card.

Scanning offers to save you as a contact. Every field you add makes the code denser, so keep only what matters.

Opens a new email, ready to send.

Use the country code (+30 for Greece) so it works from foreign phones too.
